# 套用方案后的任务产物失效

## 目标

对已停止的任务套用方案时，程序比较新的任务配置快照与旧快照，并清除受变化影响的已生成产物。之后普通“启动/续跑”必须从受影响的最早阶段继续，不能复用过期的洗稿文本或分段。

## 规则

- 改动 AI 洗稿开关、洗稿提示词、专名本地化开关、洗稿批大小或质量比例时：删除洗稿文本、专名报告、切片、TTS、字幕、成片及其下游结果；保留原始输入和图片。
- 改动 TTS 设置或朗读净化设置时：删除音频、字幕和成片；保留洗稿、切片和图片。
- 未影响任何生成阶段的配置变更仅更新快照，不删除产物。
- 日志记录配置变更触发的最早重做阶段和清理数量。
- 任务运行时仍禁止套用方案。

## 验证

- 套用改名配置后，下一次续跑不再出现 `reuse saved source and ... cleaned segments`，而会进入第 2 步。
- 仅改 TTS 配置时，洗稿与图片仍复用。
