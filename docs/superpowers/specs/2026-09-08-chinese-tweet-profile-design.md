# 中文推文配置设计

## 目标

新增制作配置“中文推文配置”，以现有“中文kiyo说”为完整基底，适用于不限定历史题材的中文小说推文视频。

## 配置内容

- 新文件：`data/profiles/中文推文配置.json`。
- 除以下字段外，逐项保留 `中文kiyo说.json` 的当前值，包括 TTS、图片模型、视频、封面、上传和浏览器配置。
- `llm_storyboard_prompt` 改为通用小说分镜规则，参照“異世界推文1”：每个小说片段仅选择一个明确、与当前内容一致的剧情瞬间；图片须跟随小说的世界观、人设、关系及情节变化；保留全年龄、安全和无文字/水印限制。
- `short_video_script_prompt` 与 `short_video_image_prompt` 同步改为通用中文小说推文规则：Short 旁白及竖屏分镜均按原文的世界观、人物和当前剧情生成，不保留历史小说或具体朝代限制。
- `youtube_description` 设为空字符串。
- 配置内部的 `active_profile` 设为“中文推文配置”，使其被载入后会显示为新名称。

## 非目标

- 不修改现有“中文kiyo说”或“異世界推文1”。
- 不改动全局 `data/settings.json` 的当前激活配置。
- 不更换上传账号、频道、标题模板或 API 参数。

## 验证

- 新文件是合法 JSON，字段集合与“中文kiyo说”一致。
- 确认说明模板为空、分镜提示不包含历史朝代锁定、原始 Kiyo 配置未变化。
