# 项目级洗稿替换类别

## 目标

让每个长片项目自行指定洗稿时允许自动本地化的专名类别，而非使用全局固定规则。项目只替换选中的类别，其他类别（例如“畜人”）保持原样。

## 用户界面

在长片项目的创建和编辑界面增加“替换类别”文本输入框。默认值为“人名”。使用中文顿号、逗号或换行分隔类别。

支持的类别为：人名、地名、家族名、组织名、机构名、种族名。输入别名“城市名”或“地点”时规范化为“地名”。空值表示只保留默认的人名类别。

## 数据与继承

类别列表保存到项目的 `project.json`。该项目创建的每一集任务把此列表写入任务设置快照，后续长片分集复用同一项目配置。其他项目不受影响。

## 洗稿行为

结构化洗稿请求仅允许模型返回项目已选中的映射类别。解析结果时，未选中的映射不应用且不导致整批正文回退；记录一条警告说明被忽略的数量。已有的项目内专名映射只在其类别仍被允许时复用。

## 校验与测试

新增配置归一化测试、项目持久化测试和洗稿过滤测试。覆盖“人名、城市名”规范化为“人名、地名”，以及种族名未被选中时不替换“畜人”。
