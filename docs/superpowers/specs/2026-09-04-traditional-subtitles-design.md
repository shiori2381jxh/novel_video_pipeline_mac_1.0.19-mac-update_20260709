# 繁体字幕开关设计

## 目标

在“画面节奏 / 视频”的字幕配置中提供“繁体字幕”开关。开启时，仅将最终生成的内嵌 ASS 字幕和导出的 SRT 字幕转换为繁体中文。

## 范围

- 新配置项默认关闭，并在 GUI 中持久化。
- 转换发生在字幕文件生成前，影响 `subtitle.ass` 和 `subtitle.srt`。
- 原始输入文本、分段、TTS 朗读稿、配音、分镜、图片提示词、标题及上传文案保持不变。
- 不转换或无法映射的字符保持原样。
- Short 字幕不在本次范围内；该开关仅控制主视频字幕。

## 实现

1. 在配置默认值中增加布尔项 `video_subtitle_traditional`。
2. 在主视频字幕设置区域加入“繁体字幕”复选框。
3. 在字幕构建层增加一个可独立测试的转换函数；开关开启时，ASS 与 SRT 共用转换后的字幕事件文本。
4. 使用本地转换逻辑，不请求外部服务，也不改写任务保存的源文本。

## 兼容性与错误处理

关闭开关时保留目前字幕输出，不改变已有行为。转换失败或不存在映射的字符按原文本输出，字幕流程不中断。

## 验证

自动化测试覆盖：关闭时原样输出；开启时简体字在 ASS 和 SRT 中转为繁体；非中文字符不变。完成后运行项目规定的 Python 编译检查。
