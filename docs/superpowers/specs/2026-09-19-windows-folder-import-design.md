# Windows 文件夹导入

## 目标

让 Windows 用户直接选择一个文件夹，递归导入其中的 TXT 和同名 MP3；已有的多选文件导入保持不变。

## 设计

macOS 维持现有的原生混选面板，可同时选择文件和文件夹。Windows 将当前单个混合入口替换为相邻的两个直接入口：`导入文件…` 和 `导入文件夹…`。

`导入文件…` 调用现有多选 TXT/MP3 文件窗口。`导入文件夹…` 直接调用 Windows 原生文件夹选择器；用户确认文件夹后，沿用现有递归扫描、去重、TXT/MP3 配对与任务创建流程。过程中不显示“是/否/取消”之类的中间选择窗口。

## 错误处理

用户取消任一系统选择器时安静返回。未发现可导入文件时，继续使用现有提示。

## 测试

增加针对 Windows 文件夹入口的回归测试，验证它直接调用目录选择器并将目录返回给导入流程；同时保留文件入口的既有行为测试。
