# Windows 文件夹导入

## 目标

让“导入文件 / 文件夹…”在 Windows 上兑现其界面承诺：用户能够选择一个文件夹，递归导入其中的 TXT 和同名 MP3；已有的多选文件导入保持不变。

## 设计

macOS 维持现有的原生混选面板，可同时选择文件和文件夹。

Windows 不尝试在同一个标准文件对话框中混选文件和文件夹。点击入口后，先显示一个小型选择对话框：

- 选择文件：调用现有多选 TXT/MP3 文件窗口。
- 选择文件夹：调用 Windows 原生文件夹选择器，并将结果传给现有递归扫描及文件配对流程。
- 取消：不创建任务，也不显示错误。

选择文件夹后沿用 `_import_files_or_folders` 的目录扫描、去重、TXT/MP3 配对与任务创建逻辑；不改变导入结果规则。

## 错误处理

用户关闭选择方式对话框或取消系统选择器时安静返回。未发现可导入文件时，继续使用现有提示。

## 测试

增加针对 Windows 选择方式的回归测试，验证“文件夹”选项调用目录选择器并将目录返回给导入流程，而不是调用文件选择器；同时保留文件选项的既有行为测试。
