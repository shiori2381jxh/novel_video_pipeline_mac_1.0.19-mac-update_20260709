# 小说项目页滚动与折叠设计

## 目标

在较矮的窗口中，让“小说项目”页的全部设置和项目列表均可访问，同时保留下方任务队列的可见空间。

## 界面行为

- “小说项目”标签页的内容区域使用独立的纵向滚动容器。
- 标签栏不随内容滚动。
- 下方任务队列不随“小说项目”页滚动，并继续保留自身的表格滚动行为。
- 鼠标指针位于“小说项目”内容区域时，Windows/macOS/Linux 的鼠标滚轮或触控板滚动该页。
- 指针位于项目列表或任务表格时，优先保留列表自身的滚动行为，避免外层页面抢走滚轮事件。

## 折叠分组

- “当前项目的统一名称与分集规则”可折叠，启动时默认展开。
- “长篇连续制作（手动开启，书库和 TXT 通用）”可折叠，启动时默认折叠。
- 点击分组标题或箭头切换展开状态。
- 折叠只改变布局，不修改、清空或保存表单数据。
- 顶部项目操作按钮和底部项目列表不放入折叠分组。

## 实现边界

- 只调整 `app/gui.py` 中“小说项目”标签页的布局和滚轮绑定。
- 不改变书库导入、文件导入、任务分类、右侧配置页及流水线业务逻辑。
- 沿用现有 Tkinter/ttk 控件风格，不引入新依赖。

## 验证

- 增加界面结构回归测试，确认滚动容器、滚动条、折叠控件和默认状态存在。
- 执行相关测试以及项目 `AGENTS.md` 指定的安全验证命令。
- 人工启动 GUI，确认小窗口中能够滚动到项目列表、折叠后布局正确，且任务队列不移动。
