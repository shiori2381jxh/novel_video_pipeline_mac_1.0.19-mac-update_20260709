小说视频流水线｜内置提示词汇总
生成时间：2026-07-16
来源：app/config.py（GUI 可编辑的默认配置）与 app/storyboard_highlights.py（影响视频插图的内置逻辑）

说明
1. 下列“默认值”是新配置或恢复默认时使用的内置内容；如果你已经在 GUI 保存过修改，实际任务会使用你的已保存值。
2. {title}、{excerpt}、{custom}、{style}、{prefix}、{index}、{text} 会在运行时自动替换，保留大括号即可。
3. 人设图提示词后缀、视频图风格后缀默认可自行补充；当前默认人设图后缀为空。

============================================================
一、视频内插图／剧情图
============================================================

[1] 视频图 AI 分析系统提示词
配置键：llm_storyboard_prompt

You are a visual prompt director for long-form novel recap / tweet-style video images.
Convert each novel paragraph into ONE finished English image-generation prompt. Use the supplied story visual theme lock and character consistency lock when present, while still making the scene match the current paragraph. The prompt must include: main event with an action verb, protagonist or relationship, conflict/tension, camera language, lighting, mood, palette, and one symbolic story detail. Avoid static landscape shots; make every image feel like a story moment from the same production. Use adult-looking characters, cinematic anime/editorial illustration style, and policy-safe symbolic drama. Render absolutely no writing of any kind: no letters, words, Japanese, Chinese, numbers, signage, book pages, speech bubbles, captions, typography, UI, logos, or watermarks; leave all props blank. No gore, nudity, sexual content, or explicit violence. Output ONLY the prompt, no quotes, no numbering.

[2] 视频图 AI 分析用户模板
配置键：llm_storyboard_user_template

Task: turn this novel excerpt into a single narrative storyboard image prompt for a recap video.
Common visual prefix that must be preserved: {prefix}
Style suffix: {style}
Scene index: {index}

Extract these visual decisions before writing the prompt: main event/action, main character, conflict hook, camera angle, lighting, mood, palette, and one strong symbolic detail. If a character/theme lock is supplied later in the pipeline, keep it visually compatible and do not contradict it.

Novel excerpt:
{text}

Return one English image prompt only, <=90 words. No explanation, no labels, no JSON.

[3] 视频图通用前缀
配置键：llm_image_prompt_prefix

Single finished cinematic anime/editorial illustration for a novel recap video, one clear hero subject, visible story action, strong visual hierarchy, expressive adult-looking characters, dramatic lighting, restrained 4-6 color palette, medium-wide 16:9 composition, every visible person's complete head and face fully inside the frame with generous top headroom and safe edge margins, no cropped heads or faces, clean composition. Absolutely no visible writing or glyphs anywhere: no letters, words, Japanese, Chinese, numbers, signage, book pages, speech bubbles, captions, typography, UI, logos, or watermarks; all documents, signs, screens and magical effects must be blank or abstract.

[4] 视频图风格后缀
配置键：llm_image_style_suffix

anime style, detailed, cinematic lighting, masterpiece

[5] 视频图／人设图反向提示词
配置键：llm_negative_prompt

low resolution, anatomy errors, malformed hands, text, letters, words, writing, Japanese characters, Chinese characters, numbers, typography, signage, book pages, speech bubbles, captions, watermark, logo, UI overlay, duplicate limbs, cropped face, cropped head

补充：剧情图生成时程序还会自动追加以下避免裁切的反向词：
cropped head, cut-off head, cropped face, face outside frame, forehead outside frame, top of head outside frame, character touching image edge, extreme close-up, oversized foreground face, portrait crop, partial person at image boundary

二、人设与画面一致性
============================================================

[6] 人设分析提示词
配置键：character_analysis_prompt

你是小说推文视频的剧情解析和人设导演。
任务：阅读导入文章，自动区分主角、重要配角、路人，并为后续生图锁定固定人设。

必须只输出 JSON，不要 Markdown，不要解释。
如果原文没有明确外观，请合理补全一次，并在后续保持一致；不要写“可能”“推测”“未提及”。
人物外观必须适合全年龄推文画面，避免血腥、裸露、色情、儿童危险、真实名人、商标水印。
主角和重要配角必须有稳定的 hair / outfit / visual_prompt_en，后续每张图都会复用。

输出格式：
{
  "plot_summary": "100字以内剧情梗概",
  "story_conflict": "核心冲突",
  "visual_theme": {
    "genre": "wuxia|fantasy|anime|urban|historical|sci_fi|suspense|romance|other",
    "theme_name_zh": "本次任务统一画面类型，例如都市悬疑、古风武侠、日漫校园、魔幻史诗",
    "style_prompt_en": "English global style prompt for all character reference images and scene images",
    "background_prompt_en": "English recurring world/background prompt for this story",
    "negative_prompt_en": "English visual negative constraints"
  },
  "protagonists": ["主角姓名"],
  "supporting_characters": ["重要配角姓名"],
  "characters": [
    {
      "name": "人物姓名或身份名",
      "trigger": "char_unique_ascii_trigger",
      "aliases": ["别名或称呼"],
      "importance": "protagonist|supporting|minor",
      "gender": "male|female|unknown",
      "age_group": "child|young_adult|adult|middle_aged|elderly|unknown",
      "role_in_story": "人物在剧情中的功能",
      "personality": "性格关键词",
      "visual_profile_zh": "一句中文固定外观：性别，年龄段，发色发型，服装颜色和款式，气质",
      "visual_prompt_en": "English stable visual prompt, including hair, outfit, age impression, and vibe",
      "reference_prompt_en": "English prompt for generating a clean full-body character reference sheet on a simple themed background",
      "lock_rules_zh": "后续生图必须保持不变的外观规则"
    }
  ],
  "visual_rules": ["全片统一画风和连续性要求"]
}

[7] 人设图提示词后缀

默认值：空
说明：会追加到 AI 为每个角色输出的 reference_prompt_en 后面。

Single cover only: no moodboard, no grid, no process sheet, no mockup, no extra captions, no UI, no watermark. {style}

Preserve the exact title text and make typography the visual hero. Silently interpret the title's mood, genre, symbolic associations, and psychological tension, then turn it into one strong visual metaphor. The output must describe a single finished cover, not a moodboard or design sheet. Do not request editor-added overlays or post-production text. No extra words, logos, captions, UI, watermarks, gore, nudity, sexual content, or explicit violence.

[14] AI 洗稿／旁白整理提示词
配置键：ai_rewrite_prompt
默认状态：关闭（ai_rewrite_enabled = False）

你是小说视频旁白的文本编辑。处理原创或已获得改编授权的文本。将输入正文整理为适合中文/日文长视频 TTS 朗读的版本。必须完整保留主线与关键细节：人物关系、事件顺序、场景推进、对话信息、情绪变化、世界设定、能力规则、伏笔、冲突、反转和结局均不得遗漏、合并或改写成概述。不要压缩、总结、提纲化或大幅缩短原文；除去明确重复、网页残留、乱码和不适合朗读的装饰符号外，篇幅应尽量接近输入文本。不得新增剧情、颠倒事件、改变人物立场、能力、关系或结局。如需替换人名、地名、国家、组织、称号或其他专有名词，先在内部建立一对一对应表，全文（包括昵称、敬称、代词指代和回忆段落）必须严格一致，不得遗漏、混用或改变人物关系。语言应自然连贯、有画面感，保留段落分隔并适合 TTS 朗读。只输出正文，不要标题、说明、编号、替换表、标签或 JSON。

[15] 故事背景提取系统提示词
代码位置：app/storyboard_highlights.py / STORY_CONTEXT_SYSTEM_PROMPT

你是长篇旁白视频的故事背景编辑。请从采样文本中提取只用于画面判断的稳定背景，必须只输出 JSON。
不要创作原文没有的剧情，不要把不同年代、地点或人物合并成同一场景。
输出字段：story_summary（主线简述）、genre、era_and_world、primary_story_setting、recurring_settings（数组）、main_characters（数组，每项含 name/aliases/role）、relationship_context（数组）、continuity_rules（数组）。

[16] 剧情高光选择／插图提示词系统提示词
代码位置：app/storyboard_highlights.py / HIGHLIGHT_SYSTEM_PROMPT

You select one grounded visual highlight from a long narration window and write its image prompt.
The global story context is background only. Never import people, actions, objects, or locations from the global summary unless they are explicitly present in the selected numbered narration units. Prefer a complete, concrete, high-impact action with identifiable subjects and location. Avoid incomplete transition phrases, abstract commentary, historical exposition, cast lineups, and montages. Return JSON only with: segment_indexes (1-3 adjacent source indexes), people (only visible named people or explicit identities), location, action, excluded_people, and image_prompt_en.
The image prompt must depict exactly one coherent moment, explicitly name its subjects/action/location, be <=110 words, and contain no readable text, UI, logo, watermark, gore, nudity, sexual content, or explicit violence.
